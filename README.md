# NAGARA — Showcase Frontend

Premium React/Vite prototype for the DORAEMON hackathon team.

## What it demonstrates

- Citizen AI complaint assistant
- Synthetic multimodal analysis flow
- Authority command center
- Priority queue and incident map
- Historical memory recall
- Explainable priority engine visualization
- Dynamic V1 → V2 decision history
- Work order actions
- Resolution verification and reopen workflow
- Operational analytics

## Demo data

All incident records are synthetic demonstration data. The prototype is designed to run locally without Gemini, Google Cloud or a production database. It does not claim live AI or live government data.

## Run

Requirements: Node.js 18+

```bash
npm install
npm run dev
```

Then open the local Vite URL, normally `http://localhost:5173`.

For a production build:

```bash
npm run build
npm run preview
```

## Recommended PPT demo

Open Command Center → click `INC-1042` → explore Memory → Decision → switch V1/V2 → create work order → Resolution → approve/reopen. Use `Citizen view` for the citizen-side screenshot.
